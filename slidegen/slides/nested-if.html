중첩 IF — 3개 이상 결과를 단계별로 분기
=IF(B2>=90, "A등급", IF(B2>=80, "B등급", "C등급"))
90 이상 → A등급  /  80~89 → B등급  /  80 미만 → C등급
①높은 기준부터 작성
②앞 조건 통과한 경우 자동 배제
③닫는 괄호 수 = IF 개수
첫 번째 IF: B2>=90?
TRUE
↓
"A등급"
FALSE
↓
두 번째 IF: B2>=80?
TRUE
↓
"B등급"
FALSE

IF(B2>=90, "A등급", IF(B2>=80, "B등급", "C등급")))  ← 괄호 2개 닫음 (IF 2개)
IF가 2개 → 마지막에 )) 두 개로 닫음  ·  IF가 N개 → 괄호도 N개
