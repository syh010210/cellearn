IFERROR — 오류가 나면 대신 보여줄 값 정하기
수식이 오류(#DIV/0! 등)를 내면, 빨간 오류 대신 정해둔 값을 보여줍니다
=IFERROR( B2/C2 , "수량오류" )
① 원래 계산할 수식    ② 오류일 때 대신 보여줄 값
❌ IFERROR 없이
처리시간수량=시간÷수량
5000#DIV/0!
3001030
수량이 0 → 0으로 나눌 수 없어 오류!
✅ IFERROR 사용
처리시간수량=시간÷수량
5000수량오류
3001030
오류를 "수량오류" 라는 글자로 바꿔줌
=IFERROR(원래 수식, 오류일 때 보여줄 값)
⚠ 자주 실수: IFERROR는 모든 오류를 가림 — VLOOKUP 못 찾을 때(#N/A) 빈칸("") 처리에 자주 사용
