오늘 날짜 넣기 · 날짜에서 연·월·일 뽑기
TODAY·NOW는 지금 날짜/시간을 자동 입력. YEAR·MONTH·DAY는 날짜에서 숫자를 뽑아냅니다
지금 날짜·시간 자동 입력
=TODAY()
→
2026-06-27
=NOW()
→
2026-06-27 14:30
TODAY = 날짜만  /  NOW = 날짜 + 시간
날짜에서 숫자 뽑기
기준: B2 = 2026-06-27
=YEAR(B2)2026
=MONTH(B2)6
=DAY(B2)27
=TODAY() · =NOW()  ·  =YEAR / MONTH / DAY(날짜)
⚠ 자주 실수: TODAY·NOW는 값이 없어도 괄호 () 반드시 붙임 · 날짜는 "-"나 "/" 둘 다 인식
