기본 수학 함수 — ABS · INT · MOD · POWER · VALUE
값을 넣으면 값이 나오는 함수들. 괄호 안에 넣는 값(인수)만 바꾸면 됩니다
ABS
부호 뗀 값(절댓값)
ABS(-3.7)
3.7
INT
정수로 내림
INT(3.9)
3
MOD
나눈 나머지
MOD(17, 5)
2
POWER
거듭제곱
POWER(2, 3)
8
VALUE
글자 → 숫자
VALUE("500")
500
⚠ INT 음수 주의INT(-3.1) = -4 (0쪽이 아니라 더 작은 정수로 내려감)
VALUE는 언제? — 숫자처럼 보이지만 글자로 저장된 데이터를 계산에 쓸 때
ABS(절댓값) · INT(내림) · MOD(나머지) · POWER(거듭제곱) · VALUE(글자→숫자)
⚠ 자주 실수: INT는 음수에서 -3.1 → -4 (버림 아님). MOD로 홀 · 짝 판별(MOD(값,2))
