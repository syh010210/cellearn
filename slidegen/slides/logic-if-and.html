IF + AND — 조건을 "모두" 만족해야 참
"~이고", "~이면서", "둘 다" 라는 말이 나오면 AND 를 씁니다
=IF( AND( B2>=80 , C2>=80 ) , "통과" , "" )
AND( ① 조건1 , ② 조건2 ) — 둘 다 참이어야 통과

알고리즘 B2≥80  그리고  SQL C2≥80
B2=85, C2=90 → 둘 다 참 → "통과"
B2=75, C2=90 → 하나 거짓 → "" (빈칸)
=AND(조건1, 조건2, …) — 모두 참이면 참, 하나라도 거짓이면 거짓
⚠ 자주 실수: AND는 혼자 못 씀 — IF 안에 넣어 =IF(AND(...), 참값, 거짓값) 형태로 사용
