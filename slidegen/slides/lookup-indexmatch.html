INDEX + MATCH — VLOOKUP이 못하는 "왼쪽으로 찾기"
VLOOKUP은 항상 첫 열에서만 찾습니다. 오른쪽 열로 찾아 왼쪽 값을 가져오려면 이 조합을 씁니다
찾는 값 (C열 = 도서명) 가져올 값 (A열 = 도서코드)
ABC
1도서코드출판사도서명
2A-101한빛파이썬기초
3B-102위키자바스크립트
도서명(C열)으로 도서코드(A열)를 찾고 싶다 → VLOOKUP 불가 (찾는 열이 더 오른쪽)
① MATCH"파이썬기초"가 C열에서 몇 번째? → 1
② INDEXA열의 1번째 값 → "A-101"
E2
fx=INDEX(A2:A3, MATCH("파이썬기초", C2:C3, 0))
INDEX(가져올 열, MATCH(찾을 값, 찾을 열, 0))
결과  →  "A-101"
찾는 열이 결과 열보다 오른쪽에 있어도 자유롭게 검색 가능
⚠ 자주 실수: INDEX의 첫 범위는 가져올(결과) 열, MATCH의 범위는 찾을 열 — 헷갈리지 말 것
