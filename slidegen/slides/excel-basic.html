엑셀 화면 구조 — 열 · 행 · 셀
셀 주소는 항상 "열(세로 알파벳) + 행(가로 숫자)" 순서로 읽습니다
ABCD
1A1B1C1D1
2A2B2C2D2
3A3B3C3D3
열 (Column) — 세로줄
맨 위 알파벳 A, B, C, D … 로 구분
행 (Row) — 가로줄
맨 왼쪽 숫자 1, 2, 3 … 으로 구분
셀 (Cell) — 한 칸
열과 행이 만나는 자리. 값 · 수식을 입력하는 곳
C3
fxC열과 3행이 만나는 칸 → 이름은 "C3"
셀 주소 = 열 알파벳 + 행 숫자  (예: C3, B2, D1)
⚠ 자주 실수: 항상 열이 먼저 — "C3"은 맞고 "3C"는 틀림
