VLOOKUP — 표에서 값을 세로로 찾아오기
왼쪽 첫 열에서 찾을 값을 찾고, 같은 줄에 있는 다른 열의 값을 가져옵니다
찾는 값 참조 범위 (드래그해서 선택한 영역) 결과 셀
AB
1도서코드도서명
2A-101파이썬 기초
3B-102자바스크립트 완전정복
4C-103리액트 실무
①A열(왼쪽 첫 열)에서 "B-102"를 세로로 내려가며 찾기
②찾은 줄(3행)에서 2번째 열의 값을 가져오기
HLOOKUP = 가로 버전첫 번째 행에서 찾고, 지정한 행 번호의 값을 가져옴
E2
fx=VLOOKUP("B-102", A2:B4, 2, 0)
① 찾을 값    ② 표 범위(드래그한 영역)    ③ 가져올 열 번호(왼쪽부터 1, 2…)    ④ 0 = 정확히 일치
결과  →  "자바스크립트 완전정복"
=VLOOKUP(찾을 값, 표 범위, 가져올 열 번호, 0)
⚠ 자주 실수: 열 번호는 표 안에서 왼쪽부터 1로 셈 (엑셀 전체 열 A·B가 아님) · 마지막 0을 빼먹으면 엉뚱한 값이 나옴
