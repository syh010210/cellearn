# CellLearn 디자인 리뉴얼 스펙

> 목적: DESIGN.md(현재 상태 인벤토리)를 기준으로 한 리뉴얼 지시서.
> 레퍼런스는 Prodmast 랜딩 — 단, "따라하기"가 아니라 **톤은 유지 + 정체성은 컴활/엑셀에서** 가져온다.
> 라벨(N/H/S/F/A/C/P/E/T/FT, SB/TB, 4-1~4-5)은 DESIGN.md와 동일.

---

## 0. 리뉴얼 원칙 (모든 작업의 판단 기준)

1. **이모지 전면 금지.** 모든 아이콘은 스트로크 1.5px 라인 SVG로 교체 (레퍼런스와 동일한 계열).
2. **엑셀 vernacular 우선.** 번호·라벨·텍스처·데모가 필요하면 일반 UI 관용구 대신 엑셀 문법(셀 주소, 수식, 그리드)을 먼저 검토.
3. **라임은 의미색이다.** 라임 `--lime`은 CTA 남발용이 아니라 "정답/완료/하이라이트된 셀" 의미로만. CTA는 딥그린이 기본.
4. **모션은 역할이 있을 때만.** 스크롤 fade-up 전 섹션 반복 금지. (아래 §7 모션 스펙 참조)
5. **팔레트는 theme.js 단일 소스.** LandingPage의 `T`, diagrams의 `C` 제거하고 theme.js import로 통일.

## 1. 디자인 토큰 (theme.js 통합안)

### 색상
```js
// base
bg:        '#f2f4f2',   // 오프화이트 (기존 #edf0ee보다 살짝 중립)
surface:   '#ffffff',
panel:     '#f7f9f8',
border:    '#e3e8e5',
gridline:  '#eaefec',   // ★ 신규: 셀그리드 텍스처용 (border보다 옅게)

// ink
ink:       '#12211d',
inkSoft:   '#5c6b66',
inkFaint:  '#8b988f',

// brand
green:     '#123a33',   // 딥그린 (유지)
greenDeep: '#0d2a25',   // 푸터/다크섹션
lime:      '#c8f26a',   // ★ 의미색으로 강등: 정답셀/완료/하이라이트 전용
limeSoft:  '#eef9d8',   // 라임 틴트 배경

// semantic
correct:   '#1f9d55',
wrong:     '#d64545',
warn:      '#c98a1a',
```
- 랜딩의 가격섹션 블랙 `#0b0c0e` → `greenDeep`으로 교체 (블랙 섹션 폐지, 그린 계열로 일원화).
- diagrams 다크 팔레트 폐지 → 밝은 톤 + `gridline` 셀그리드 배경으로 재작성 (§6).

### 타이포
- 본문: **Pretendard** (Noto Sans KR 대체). weight 400/600/700.
- 데이터 표기 전용 모노: **JetBrains Mono** — 함수명, 수식, 셀 주소(A1), 점수, 금액에만. 헤드라인·본문에 사용 금지.
- 헤드라인: 800 일변도 폐지. `h1: 34~44px/700`, `h2: 26~30px/700`, `h3: 18~20px/600`. 위계는 굵기보다 크기+자간(-0.01~-0.02em)으로.
- 함수명·수식은 항상 모노 + `green` 색: `=VLOOKUP(...)` 형태.

### 형태(라운드) — 3단계로 위계화
- 대형 컨테이너(섹션 카드, 패널): `radius: 16`
- 일반 카드·입력: `radius: 10`
- 버튼: `radius: 10` — **알약(999) 폐지.** 예외: 상태 뱃지/칩만 999 허용.
- 그림자: 기본 없음(현행 유지). 모달·sticky 요소만 `0 8px 24px rgba(18,33,29,.08)`.

### 아이콘
- 라이브러리: lucide-react (이미 React 프로젝트, 스트로크 계열이라 레퍼런스 톤과 일치).
- 매핑: 📖→BookOpen, 🧮→Table2, ✅→CheckCircle2, 📝→PenLine, ❌→XCircle, 📊→BarChart3, 📂→FolderOpen, ↗→ArrowUpRight(단, 카드 우상단 ↗ 장식은 **삭제**, hover 시에만 등장 §7).
- 크기 18~20px, strokeWidth 1.5, 색은 `inkSoft` 기본 / 활성 시 `green`.

## 2. 랜딩 페이지 리뉴얼

### N. 네비바
- 유지. 로고 옆 "CellLearn" 워드마크에 모노 폰트로 `=` 프리픽스 검토: `=CellLearn` (과하면 생략).
- "학습 시작" 버튼: 알약 → radius 10.

### H. 히어로 — ★ 최우선 작업
현행 "뱃지→제목→설명→버튼2" 공식 폐지. 구성:
- 좌측: 제목 + 설명 + CTA 1개(딥그린 "무료로 시작") + 보조 텍스트 링크("커리큘럼 보기").
  - 제목 예시: "컴활 실기, 브라우저에서 바로 친다" — 카피는 기능 설명이 아니라 경험 서술로.
- 우측: **라이브 MiniExcel 데모** (기존 MiniExcel.jsx 재사용, 읽기전용 아님 — 방문자가 실제로 셀 클릭/입력 가능).
  - 초기 상태: 페이지 로드 시 수식 타이핑 오케스트레이션 (§7-1).
  - 데모 하단에 모노 캡션: `설치 없음 · 채점 즉시 · 실제 시험 함수 60+`
- 배경: 히어로 영역에만 `gridline` 색 셀그리드 패턴 (아주 옅게, opacity 0.5 수준).
- 모바일: "PC에서 이용" 안내 유지하되 데모는 정적 스크린샷+재생 오버레이로 대체.

### S. 스탯 줄
- 4칸 → 3칸으로 축소, "신규 오픈"과 안 맞는 과장 숫자 제거.
- 내용 예: `60+ 시험 범위 함수` / `100% 브라우저 실습` / `즉시 파일 채점`.
- 숫자는 모노 폰트 + 카운트업 모션 1회 (§7-2). 칸마다 색 다르게 하던 것 폐지 → 전부 `surface` 카드 + 좌측 2px `green` 보더로 통일.

### F. 학습 방식 (딥그린 섹션)
- 6카드 유지하되:
  - 이모지 → lucide 라인 아이콘 (§1 매핑).
  - 우상단 ↗ 상시 노출 삭제 → hover 시 슬라이드 인.
  - 카드 번호를 셀 주소로: 각 카드 좌상단에 모노 소형 라벨 `A1` `B1` `C1` `A2` `B2` `C2` (그리드 위치와 실제 일치시킬 것).
- 섹션 제목 위 eyebrow 라벨 쓰지 말 것. 제목 문장으로 바로 시작.

### A. 핵심 강점
- 가짜 대시보드 목업 → **실제 Dashboard.jsx 컴포넌트를 데모 데이터로 렌더** (스크린샷/목업 아님). 목업 티 제거가 목적.
- ◆ 불릿 → CheckCircle2 아이콘, 텍스트는 현행 유지.

### C. 커리큘럼
- 번호뱃지 `01 02 03…` → 모노 셀 주소 스타일 `1강` 대신 `L01` `L02`… 또는 엑셀 시트탭 모양 뱃지. 시트탭 모티프 추천: 카드 상단에 시트탭 형태(사다리꼴/라운드 상단)로 차시명 표시.
- 카드 hover: 배경 `limeSoft` 틴트 (정답 셀 하이라이트 은유).

### P. 가격
- 블랙 섹션 → `greenDeep` 배경으로 교체.
- 금액은 모노 폰트. 플랜 카드 radius 16, 버튼 radius 10.
- 1급 강조는 현행(딥그린 카드) 유지하되, "추천" 뱃지는 라임 칩(999 허용 예외).

### E. 함수/엔진
- 함수 칩 16개: 모노 폰트 + `panel` 배경 + radius 6 (칩만 각지게 — 코드 토큰 느낌).
- hover 시 해당 함수의 한 줄 시그니처 툴팁: `VLOOKUP(찾을값, 범위, 열번호, [방법])`.

### T. CTA 밴드 / FT. 푸터
- CTA 버튼: 라임 → 흰 배경 + `green` 텍스트 (다크 위 형광 CTA 클리셰 회피).
- 푸터 현행 유지, 색만 `greenDeep` 토큰으로.

## 7. 모션 스펙 (전체)

**공통 규칙:** `prefers-reduced-motion` 존중(모든 모션 스킵). 이징 `cubic-bezier(0.22, 1, 0.36, 1)`. 스크롤 진입 fade-up을 모든 섹션에 거는 것 금지 — 아래 지정된 것만.

### 7-1. 히어로 오케스트레이션 (페이지당 1회, 자동 재생)
1. MiniExcel 그리드 등장 (opacity, 300ms)
2. 셀 B2에 커서 이동 → `=VLOOKUP(A2,D2:E10,2,0)` 타이핑 (글자당 40ms, 모노)
3. Enter → 결과값 계산되며 셀이 `limeSoft` 플래시 (400ms)
4. 캡션 페이드 인
- 총 3초 이내. 재생 후 데모는 자유 조작 가능 상태로 전환.

### 7-2. 스탯 카운트업
- 뷰포트 진입 시 1회, 800ms, 모노 숫자. 재스크롤 시 반복 금지.

### 7-3. 진도바
- 마운트 시 0→현재값 채움 600ms. 100% 도달 순간에만 라임 전환 + 살짝 오버슛.

### 7-4. 사용자 액션 응답 모션 (앱 내부의 기본 모션 철학)
- 채점 결과: 카드가 아래에서 12px 슬라이드+페이드 (250ms), 셀별 결과는 40ms 스태거.
- 퀴즈 정답 플래시: `limeSoft` 배경 1회 깜빡 (400ms).
- 탭/개념 전환: 콘텐츠 crossfade 200ms (슬라이드 방향성 불필요).
- 카드 hover: translateY(-2px) + ↗ 아이콘 슬라이드 인 (150ms). 랜딩 F/C 섹션만.
