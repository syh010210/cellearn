작성일: 2026-09-10
범위: 계산작업을 제외한 전 영역 (기본작업-1·2·3, 분석작업-1·2, 매크로작업, 차트작업). 계산작업은 `계산작업_유형.md`, 기본작업-2 상세는 `기본작업2_유형.md` 참조. 이 파일 8절에 기본작업-2 보강분이 있다.

## 0. 시험 전체 구조

```
문제1 기본작업(20점)   기본작업-1 자료 입력 5점 / 기본작업-2 서식 5문항 × 2점 / 기본작업-3 5점
문제2 계산작업(40점)   5문항 × 8점
문제3 분석작업(20점)   분석작업-1 10점 / 분석작업-2 10점
문제4 기타작업(20점)   매크로작업 2문항 × 5점 / 차트작업 5문항 × 2점
```

- 시트 8개 고정: `기본작업-1, 기본작업-2, 기본작업-3, 계산작업, 분석작업-1, 분석작업-2, 매크로작업, 차트작업`. 시나리오 문제가 있으면 정답 파일에 `시나리오 요약` 시트가 하나 더 생긴다(분석작업 시트 바로 왼쪽).
- 각 문제 머리 문장은 고정: `주어진 시트에서 다음 과정을 수행하고 저장하시오.` (길벗은 `다음 작업을`)
- 각 시트 지시문 첫 줄도 고정: `'기본작업-2' 시트에 대하여 다음의 지시사항을 처리하시오. (각 2점)` / `'기본작업-3' 시트에서 다음의 지시사항을 처리하시오. (5점)` / `'분석작업-1' 시트에 대하여 다음의 지시사항을 처리하시오. (10점)` / `'매크로작업' 시트의 [표]에서 다음과 같은 기능을 수행하는 매크로를 현재 통합 문서에 작성하고 실행하시오. (각 5점)` / `'차트작업' 시트의 차트를 지시사항에 따라 아래 그림과 같이 수정하시오. (각 2점)`
- 매크로·차트에는 고정 경고문이 붙는다: `※ 셀 포인터의 위치에 상관없이 현재 통합 문서에서 매크로가 실행되어야 정답으로 인정됨`, `※ 차트는 반드시 문제에서 제공한 차트를 사용하여야 하며, 신규로 작성 시 0점 처리됨`
- 지시 문장의 어미는 전부 `~하시오`. 세부 조건은 `▶` 줄. 순서가 중요한 경우 `단, ~` 또는 `위에 명시된 순서대로 처리하시오`.

## 1. 기본작업-1: 자료 입력 (5점)

**문장 (고정)**
> '기본작업-1' 시트에 다음의 자료를 주어진 대로 입력하시오. (5점)

지시문 아래에 엑셀 화면 캡처(행·열 머리글 포함)가 들어간다. 텍스트 지시는 없다.

**표 구조 (25회)**: 1행 제목, 2행 빈 행, 3행 머리글, 4행부터 데이터 5~8행, 열 4~8개. 열 종류: 문자(이름·항목·구분), 숫자(금액·수량), 날짜(2023-01-01), 시각(10:38), 괄호가 든 문자(삼겹살(500G)), 별표 마스킹(박*선), 코드(GP-1). 문제 파일에는 A1 제목만 있거나 완전히 비어 있다.

**함정**: 날짜를 문자로 입력하면 오답. 숫자에 쉼표를 직접 치면 문자가 된다. 열 순서·오타. 제목 셀 위치(A1).

**실전모드 결정**: 캡처 이미지를 못 넣으므로 표 원본을 지문 영역(J열 이후)에 회색 배경으로 그대로 제공하고, 학생이 A1부터 옮겨 적게 한다. 채점은 셀 값·자료형(날짜는 date, 숫자는 number) 비교.

### 3-1. 조건부 서식 (10회)

**문장 뼈대**
> [A4:F15] 영역에서 X가 ~인 행 전체에 대하여 글꼴 색을 '표준 색 – 빨강', 글꼴 스타일을 '굵게'로 지정하는 조건부 서식을 작성하시오.
> ▶ AVERAGE 함수 사용
> ▶ 단, 규칙 유형은 '수식을 사용하여 서식을 지정할 셀 결정'을 사용하고, 한 개의 규칙으로만 작성하시오.

**원문 (11회 중 6회)**
- 2023-1: '프로야구 2021~2022'에서 2021년 승률이 '50%' 이상이면서 2022년 승률이 '50%' 이상인 행 전체에 대하여 글꼴 스타일 '굵은 기울림꼴', 글꼴 색 '표준색-파랑'으로 지정하는 조건부 서식을 작성하시오. ▶ AND 함수 사용 ▶ 단, 규칙 유형은 '수식을 사용하여 서식을 지정할 셀 결정'을 사용하고, 하나의 규칙으로만 작성하시오.
- 2023-3: [A4:E12] 영역에서 부서가 '식품부'이면서 실적이 평균이상인 행 전체에 대하여 채우기 색 '표준색 – 연한 녹색'을 적용하고, 부서가 '가전부'이면서 실적이 평균이상인 행 전체에 대하여 글꼴 스타일 '굵게', 글꼴 색 '표준색 – 빨강'을 적용하는 조건부 서식을 작성하시오. ▶ AND, AVERAGE 함수 사용 ▶ 단, 규칙 유형은 '수식을 사용하여 서식을 지정할 셀 결정'을 사용하시오. (규칙 2개)
- 2024상시01: [A4:F15] 영역에서 대출금액이 대출금액 평균보다 큰 경우 행 전체에 대하여 글꼴 색을 '표준 색 – 빨강', 글꼴 스타일을 '굵게'로 지정하는 조건부 서식을 작성하시오. ▶ AVERAGE 함수 사용
- A형: [A4:H18] 영역에서 학번이 '2019'로 시작하는 행 전체에 대하여 글꼴 색을 '표준 색-빨강'으로 지정하는 조건부 서식을 작성하시오. ▶ LEFT 함수 사용
- B형: [A4:G15] 영역에 대하여 직위가 '주임'이면서 총급여가 4,000,000 미만인 행 전체에 대하여 글꼴 스타일을 '굵게', 글꼴 색을 '표준 색-파랑'으로 지정하는 조건부 서식을 작성하시오. ▶ AND 함수 사용
- 2026상시02: [A4:F15] 영역에서 판매금액이 판매금액 평균보다 큰 행 전체에 대하여 글꼴 색을 '표준 색 - 빨강', 글꼴 스타일을 '굵은 기울임꼴'로 지정하는 조건부 서식을 작성하시오. ▶ AVERAGE 함수 사용

**정답 수식 (10회 전부)**

| 회차 | 적용 범위 | 수식 | 서식 |
|---|---|---|---|
| 2023-1 | A4:D13 | `=AND($C4>=50%,$D4>=50%)` | 굵은 기울임꼴, 파랑 |
| 2023-3 | A4:E12 | `=AND($C4="식품부",$E4>=AVERAGE($E$4:$E$12))` / `=AND($C4="가전부",$E4>=AVERAGE($E$4:$E$12))` | 채우기 연한 녹색 / 굵게+빨강 |
| 2024상시01 | A4:F15 | `=$D4>AVERAGE($D$4:$D$15)` | 빨강, 굵게 |
| A형·2025-7 | A4:H18 | `=LEFT($A4,4)="2019"` | 빨강 |
| B형 | A4:G15 | `=AND($C4="주임",$G4<4000000)` | 굵게, 파랑 |
| 상시기출5 | A4:F13 | `=AND($F4="합격",$E4>=85)` | 굵게, 파랑 |
| 2025-4 | A4:G16 | `=$F4>AVERAGE($F$4:$F$16)` | (dxf) |
| 2025-6 | A4:F15 | `=$F4>=MEDIAN($F$4:$F$15)` | 빨강 |

**슬롯**
- 조건 수: 1개(비교·평균·LEFT) / 2개 AND / 규칙 2개(드묾)
- 조건 함수: 없음(단순 비교) / AVERAGE / MEDIAN / LEFT·RIGHT / AND
- 비교 대상: 상수(4,000,000, 85, 50%) / 평균·중간값 / 문자열("주임", "합격") / 시작 문자
- 서식: 글꼴 색(빨강·파랑) / 글꼴 스타일(굵게·기울임꼴·굵은 기울임꼴) / 채우기 색(연한 녹색·노랑). 조합 1~2개
- 적용 범위: 머리글 제외 데이터 행 전체 [A4:F15]

**함정**
- 열만 절대참조(`$C4`). `$C$4`로 쓰면 첫 행 조건이 전체에 적용. `C4`면 열이 밀린다.
- 적용 범위는 머리글 제외 데이터만. 머리글 포함하면 오답.
- AVERAGE 범위는 절대참조.
- '50%'는 0.5. 셀이 백분율 서식이면 `>=50%` 그대로 써도 된다.
- '표준 색'과 '테마 색' 구분. '굵은 기울임꼴'은 둘 다 체크.

**채점 항목**: 규칙 수 / sqref(적용 범위) / 수식 정규화 비교(대소문자·공백·`$` 위치까지) / dxf 글꼴 b·i·color rgb, fill fgColor.

## 9. 실전모드 생성·채점 메모 (계산작업 제외)

**생성기 조립 규칙**
- 기본작업-3: 고급 필터 44% / 조건부 서식 40% / 텍스트 나누기 16%. 데이터 표 12~15행, 5~8열. 조건부 서식은 조건 함수(없음·AVERAGE·MEDIAN·LEFT·AND) + 서식 2속성. 고급 필터는 조건 2개(OR 60%) + 열 추출 여부 60%.
- 분석작업: {부분합, 피벗} 중 1개 + {시나리오, 통합, 데이터표, 정렬, 목표값} 중 1개. 순서는 무작위. 부분합·피벗은 원본 표 15~20행. 시나리오는 정답에 '시나리오 요약' 시트가 생기므로 채점기가 시트 추가를 허용.
- 매크로: ① 계산(산식 50% / AVERAGE 30% / SUM 20%) ② 서식(채우기 50% / 글꼴 색 20% / 셀 스타일·표시 형식·테두리). 단추·도형 종류와 위치를 지시.
- 차트: 묶은 세로 막대를 기본 생성 → 5항목을 [범위 수정, 종류 변경, 제목/축, 레이블, 범례/영역 서식] 순으로 뽑는다. 원형은 계열 1개 데이터, 혼합·보조축은 값 단위가 다른 2계열 데이터가 필요.

**채점 위치별 파서**
- 조건부 서식·정렬·시나리오·데이터표·부분합: sheet XML
- 피벗: pivotTables/*.xml + pivotCacheDefinition
- 차트: charts/chart*.xml
- 매크로: vbaProject.bin (MS-OVBA 압축) + drawings/vmlDrawing·drawing*.xml의 macro 속성
- 통합·목표값·텍스트 나누기·기본작업-1: 셀 값

**아직 못 정한 것**
- 채점 실행 위치(브라우저 vs 서버). VBA·피벗·차트 XML 파싱은 JSZip으로 가능하지만 vbaProject.bin 압축 해제는 직접 구현 필요.
- <그림> 없이 부분합·피벗 지시문만으로 배치가 유일하게 결정되는지. 피벗은 필터/행/열/값과 옵션을 전부 문장에 적으면 된다(길벗 양식). 부분합은 그룹 열·함수·항목 열·순서를 적으면 유일.
- 기본작업-1 표 원본을 지문에 노출하는 방식(복사-붙여넣기로 풀리는 문제). 실제 시험도 타이핑이 목적이므로 허용할지 결정.
