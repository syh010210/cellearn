## 목표

학생이 약한 영역을 골라 모의고사를 만들면, 실제 시험과 같은 8시트 엑셀 파일 하나가 생성된다. 각 시트의 표 오른쪽에 지문이 들어 있고, PDF는 없다. 학생은 파일을 내려받아 엑셀에서 풀고 저장해 업로드한다. 채점기가 항목별로 정답/오답과 사유를 돌려주고 오답노트에 쌓인다. 몇십 번을 만들어도 매번 다른 문제가 나온다.

## 원리: 생성이 아니라 조립

실행 시점에 AI를 쓰지 않는다. 유형 템플릿 × 데이터 세트 × 슬롯 값을 시드로 조합한다.

1. 유형 템플릿 — 문장 뼈대, 슬롯, 정답 설정값, 함정. 영역마다 기출 정답 파일을 문제 파일과 셀 단위로 비교해 뽑는다. (전 영역 완료: 기본작업-2 → 기본작업2_유형.md, 계산작업 → 계산작업_유형.md 20개 소유형 + 워딩 템플릿, 나머지 → 실전모드_시트별_유형.md)
2. 데이터 세트 — 주제(판매 현황, 회원 관리, 예약 현황, 도서 입고 …)별 열 구성과 값 범위. 이름·상품·날짜·금액은 풀에서 추출. 표 형태는 1행 제목, 2행 빈 행, 3행 머리글, 4행부터 6~10행 데이터로 고정.
3. 조립기 — 영역별 구성 규칙에 따라 슬롯 값을 뽑아 문항을 만들고 정답을 파일 상태로 만든 뒤 검증. 시드를 저장하면 같은 모의고사를 재현할 수 있다.

약한 영역 선택 = 조립기에 제약 걸기. 예: 기본작업-2 표시 형식 강화 → ③④에 숫자 형식·날짜 형식 각 1개. 오답노트 데이터로 "많이 틀린 유형 자동 선택"도 같은 방식.

## 파일 구조

- 시트 8개: 기본작업-1, 기본작업-2, 기본작업-3, 계산작업, 분석작업-1, 분석작업-2, 매크로작업, 차트작업
- 지문은 파일에 넣지 않는다. ExamView 문제 패널에 표시한다. 파일에는 데이터만 있다.
- 모의고사 ID를 숨김 시트 또는 문서 속성에 심어 업로드 시 매칭.
- 정답은 파일에 넣지 않는다. 시드와 문제 스냅샷을 Supabase에 저장하고 정답은 시드로 재생성.
- 지금은 xlsx. 매크로작업 단계에서 xlsm 생성·왕복 보존을 검증한 뒤 전환. (openpyxl 노선 폐기 — 채택한 결정 1·2 참조)
- 차트작업은 생성 시점에 차트를 만들어 넣는다(막대·꺾은선·원형).

## 채점 방식 (영역별)

| 영역 | 확인 |
|---|---|
| 기본작업-1 | 셀 값 비교 |
| 기본작업-2 | 글꼴·맞춤·표시 형식 코드·테두리·셀 스타일·이름 정의·메모 |
| 기본작업-3 | 조건부 서식 규칙(수식·범위·서식), 고급 필터(조건 범위 값·결과 값), 텍스트 나누기(결과 값) |
| 계산작업 | 결과값 일치 + 함수 목록 준수 (채택한 결정 4 참조). 수식 동치 비교는 오답 사유 안내용 |
| 분석작업 | 부분합(SUBTOTAL 수식·그룹), 피벗(pivotTable XML 필드 배치·옵션), 목표값(결과값), 시나리오(시트 XML), 데이터 표(TABLE 수식), 통합(결과값), 정렬(행 순서) |
| 매크로작업 | vbaProject.bin 모듈 코드(매크로 이름·동작), 단추·도형 텍스트와 매크로 연결 |
| 차트작업 | 차트 XML(종류·범위·제목·축·레이블·범례·스타일) |

사유는 항목 단위. 예: "②번: 셀 스타일이 '강조색 4'가 아니라 '강조색 2'입니다", "④번: 표시 형식이 #,##0"천원"입니다. 절삭 쉼표가 빠져 70000천원으로 표시됩니다".

## 채택한 결정 (2026-09-11)

1. 채점 실행 위치: 브라우저. xlsx-js-style + JSZip XML 파싱. openpyxl/oletools 노선 폐기. 매크로(vbaProject.bin)는 매크로 단계에서 재검토.
2. 파일 형식: 지금은 .xlsx. 매크로 단계 진입 전에 xlsx-js-style의 .xlsm 생성·왕복 보존을 별도 검증.
3. 저장: Supabase Storage 사용 안 함. 신규 테이블 exam_attempts (user_id, grade, seed, config jsonb, problem_set jsonb, items jsonb, correct, total, created_at). 항목별 테이블은 통계 필요 시 추가. SQL은 idempotent 마이그레이션 파일로만 작성하고 사람이 SQL Editor에서 실행.
4. 계산작업 채점 기준 (실제 시험 기준): (a) 결과값 일치 — 텍스트는 완전 일치, 숫자는 표시 형식 무시 (b) ▶ 함수 목록의 함수를 전부 사용, "~ 중 알맞은 함수"는 후보 중 1개 이상 (c) 목록 밖 함수 사용 시 오답 (d) 수식 문자열 일치는 채점에 쓰지 않고, astEqualFormula/argDiffReason은 오답 사유 안내에만 사용.
5. 문제 모델: 조립기(유형 템플릿 × 데이터 세트 × 시드)의 출력은 기존 문제 JSON 스키마와 같은 모양의 "문제 인스턴스". examBuilder/examGrader는 그대로 쓰고 문제 공급원만 바뀐다. 고정 문제 = 시드 고정 인스턴스.
6. 지시문 위치: 파일에 넣지 않는다. ExamView 문제 패널(좁은 세로 레이아웃, 시트 칩 전환)에 표시. examBuilder는 표만 그린다. 인쇄 기능 없음. (2026-09-14, 웹 패널 목업 검토 후 결정)
7. 시험 화면 기능 (2026-09-14, (a)(b) 2026-09-15 교체):
   (a) 타이머 40분. 시작 버튼 = 파일 다운로드 + 시작. 40:00부터 감소, 10분·5분 남을 때 색 변경. 0이 되면 멈추지 않고 "+MM:SS 초과"로 계속 센다. **경과 = Date.now() - startedAt 벽시계 기준**: 새로고침·탭 전환·창 최소화 어떤 상황에서도 계속 흐른다. 정지·재개 로직 없음. 저장하는 값은 startedAt 하나뿐(경과는 저장하지 않고 매번 계산). 채점 시 elapsed_ms = 채점 시각 - startedAt.
   (b) 일시정지·응시 포기 버튼 없음. 종료 규칙(phase=running 에만):
       - 앱 내 다른 화면 이동(사이드바·대시보드 링크 등): 이동 전 "시험을 종료할까요? 종료하면 이 응시는 채점되지 않고 사라집니다." [종료][계속 풀기]. 라우터가 없어 전역 examGuard 플래그를 App 네비게이션 핸들러가 확인. 종료 시 exam:current·exam:attempt 삭제 후 이동, 계속 풀기면 이동 취소.
       - 창·탭 닫기: beforeunload 브라우저 기본 확인창. 실제로 닫히면 응시는 버려진다.
       - 새로고침 구분: 시작 시 sessionStorage "exam:tab"=attemptId. ExamView 마운트 시 running attempt 가 있어도 exam:tab 이 없으면(새 탭·창 닫았다 열기) 폐기하고 구성 화면으로, 있으면(같은 탭 새로고침) 복원해 이어감(경과는 벽시계라 자동으로 맞음).
       - 다른 브라우저 탭·다른 프로그램 전환: 아무 일도 없음. 시간은 계속 간다.
       - 채점 완료(graded)는 종료 규칙에 걸리지 않고 [새 응시]까지 유지. 새 탭·재접속에서도 결과가 보인다.
   (c) 업로드 시 "시간을 멈추고 채점할까요?" 확인. 확인하면 타이머 종료 + 채점. 취소하면 계속.
   (d) 결과에 소요 시간과 40분 초과 여부 기록.
   (e) 배점 표시: 시트 칩 20/40/20/20, 항목 옆 각 N점. (시트가 늘 때 추가)
   (f) 항목별 깃발. 칩에 개수. 채점 결과와 함께 저장해 "표시하고 맞음 / 표시 없이 틀림"을 오답노트에 넘긴다.
   (g) 채점 결과를 지문 항목 옆에 표시. 사유 + 해당 차시 링크.
   넣지 않음: 시험 안내문, 완료 체크, 일시정지, 인쇄, 힌트·구문 도움말·정답 미리보기.
8. 기본작업-2 채점 경로 (2026-09-14 왕복 실험 결과): JSZip으로 styles.xml·sheetN.xml·workbook.xml·comments·vml을 직접 파싱. xlsx-js-style read는 글꼴·맞춤·테두리를 내려주지 않으므로 서식 채점에 쓰지 않는다(값·수식 채점에만 유지). 테두리는 셀이 아니라 모서리(edge) 단위로 채점(인접 두 셀 중 한쪽에만 기록됨). '선택 영역의 가운데로'=centerContinuous, '병합하고 가운데'=center+mergeCells로 구분. 셀 스타일은 이름이 아니라 builtinId(+fill theme 인덱스)로 판정.

## 주의

기출 파일은 기풍쌤 복원본이며 상업적 이용 불가. 유형·문장 구조 분석에만 쓰고 지시문 원문·표 데이터는 셀런에 넣지 않는다. 시험 지시문 형식("'선택 영역의 가운데로', 글꼴 크기 '14'…")은 상공회의소 출제 양식이라 같은 문장이 되지만, 데이터와 표시 예 값은 새로 만든다.
