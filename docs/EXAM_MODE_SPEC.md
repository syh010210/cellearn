# 실전 모드(Exam Mode) 설계 — 확정본

> 전 차시 완주 후 열리는 모드. **컴활 2급 실기 시험지 그대로**의 모의고사를 구성해
> **실제 엑셀 파일(.xlsx)로 내려받아 풀고 → 업로드하면 실채점**한다.
> (1급은 이후 확장. 문제는 기출 유형 기반으로 새로 창작.)

---

## 1. 시험지 구조 (2급 실기 표준)

한 회 모의고사 = 아래 8개 작업(시트)으로 구성. 실제 시험과 동일.

| 슬롯 | 시트 | 유형(선택지) | 채점 방식 |
|---|---|---|---|
| 기본작업-1 | 데이터 입력 | (고정) 입력 | 셀 값 일치 |
| 기본작업-2 | 서식 | (고정) 셀 서식 | 서식 XML 검사 |
| **기본작업-3** | 부분 기능 | **조건부 서식 / 고급필터 / 텍스트 나누기** 중 택1 | 유형별 XML/값 검사 |
| **계산작업** | 함수 5문제 | 차시 1~8 함수 유형 조합 | **정답 수식 문자열 일치** |
| **분석작업-1** | 분석 | **피벗 / 부분합 / 데이터표 / 시나리오 / 통합 / 목표값 / 정렬** 중 택1 | 유형별 검사 |
| **분석작업-2** | 분석 | 위와 동일(1과 다른 유형) | 유형별 검사 |
| 매크로작업 | 매크로 | (고정) 매크로 2개 + 도형 | vbaProject/도형 검사 |
| 차트작업 | 차트 | (고정) 차트 요소 | chart XML 검사 |

---

## 2. 두 가지 모드

### A. 표준 모의고사 (초반 10회) — 고정 구성
- 10회 세트. 각 회는 **난이도 하 4 · 중 3 · 상 3** 문항 배분으로 자동 구성.
- 난이도는 각 작업 문제에 매겨진 `difficulty`(하/중/상) 기준으로 슬롯을 채운다.
- 사용자는 회차만 고르고 바로 시험지 다운로드.

### B. 커스텀 모의고사 — 사용자가 유형 선택
- **작업별 체크박스**로 출제 유형을 직접 지정:
  - 기본작업-3: [조건부 서식] [고급필터] [텍스트 나누기] 중 1개 선택
  - 계산작업: 함수 유형 다중 선택(예: [찾기참조] [논리] [DB] …) → 5문제 슬롯 구성
  - 분석작업: [피벗][부분합][데이터표][시나리오][통합][목표값][정렬] 중 **2개 선택** → 분석-1·2로 출제
- 선택에 맞는 문제를 뱅크에서 뽑아 시험지(.xlsx) 조립 → 다운로드.

---

## 3. 문제 뱅크 데이터 모델 (`src/data/exam/*.json`)

작업(section)·유형(subtype)·난이도로 태깅. 유형 기반 창작 문제.

```jsonc
{
  "id": "calc-lookup-0001",
  "section": "계산",            // 기본1|기본2|기본3|계산|분석|매크로|차트
  "subtype": "lookup",          // 유형 키(아래 §4)
  "difficulty": "하",           // 하|중|상
  "grade": "2급",
  "title": "지점별 등급 조회",
  "instruction": "…문제 지시문…",
  "sheetName": "계산작업",       // 시험지에 들어갈 시트명(또는 표 위치)
  "table": [ ["지점","매출",…], … ],   // 주어지는 표(값)
  "answers": [ { "cell": "E3", "formula": "=VLOOKUP(...)" }, … ],  // 정답(채점 기준)
  "fillDown": { "from": "E3", "to": "E10" }   // (선택) 자동 채우기 구간
}
```

- **계산작업**: `answers`의 정답 수식 문자열 일치로 채점(공백 제외). 실제 컴활 채점과 동일.
- 조작형(기본3/분석/매크로/차트): §5의 유형별 채점 규격을 각 문제에 맞게 확장.

---

## 4. 유형(subtype) 키 목록

- 계산: `ref` 참조 · `text` 문자열 · `stat` 통계 · `lookup` 찾기참조 · `db` DB · `math` 수학 · `date` 날짜 · `logic` 논리
- 기본작업-3: `condformat` 조건부서식 · `advfilter` 고급필터 · `text2col` 텍스트나누기
- 분석: `pivot` 피벗 · `subtotal` 부분합 · `datatable` 데이터표 · `scenario` 시나리오 · `consolidate` 통합 · `goalseek` 목표값 · `sort` 정렬

---

## 5. 채점 방식 (작업별) — 구현 난이도 순

xlsx는 zip(XML). SheetJS로 값·수식은 읽되, 서식/피벗/차트/매크로는 내부 XML을 직접 파싱해야 한다.

| 작업 | 채점 방법 | 난이도 |
|---|---|---|
| 계산작업 | 셀 `.f`(수식) 문자열 비교 (기존 excelGrader 재사용) | ★ 쉬움 (지금 가능) |
| 기본작업-1 | 셀 값 비교 | ★ 쉬움 |
| 텍스트 나누기 | 결과 열들의 값 비교 | ★ 쉬움 |
| 고급필터 | 결과 범위 값 비교 | ★★ |
| 조건부 서식 | `xl/worksheets`의 `<conditionalFormatting>` 규칙(수식·범위) 파싱 | ★★★ |
| 서식(기본2) | `styles.xml` + 셀 스타일 파싱 | ★★★ |
| 분석(피벗/부분합/데이터표/시나리오/통합/목표값/정렬) | 결과 표 값 비교(부분합·통합·목표값·정렬·데이터표) 또는 정의 XML(피벗·시나리오) | ★★★~★★★★ |
| 매크로 | `xl/vbaProject.bin` 존재/모듈, 도형 연결 | ★★★★ |
| 차트 | `xl/charts/chart*.xml`의 종류·계열·축 파싱 | ★★★★ |

> **원칙**: 값·수식으로 채점 가능한 것(계산·입력·텍스트나누기·고급필터·부분합·통합·목표값·정렬·데이터표)을 **1차 구현**, 정의 XML 파싱이 필요한 것(조건부서식·서식·피벗·시나리오·차트·매크로)은 **2차**.

## 6. 시험지 조립(.xlsx 생성)

- `src/utils/examBuilder.js`: 선택된 문제들을 받아 8개 시트를 가진 시험지 워크북 생성(SheetJS/xlsx-js-style).
  - 각 작업 문제의 `table`·`instruction`을 해당 시트에 배치(정답 셀은 비움).
  - 파일명 예: `컴활2급_실전모의고사_01.xlsx`.
- `src/utils/examGrader.js`: 업로드 xlsx를 열어 §5 규격으로 작업별 채점 → 작업별 배점·정오답·해설 반환.

---

## 7. 화면 흐름 (ExamView)

1. **모드 선택**: [표준 모의고사 10회] / [커스텀 구성]
2. 표준: 회차 카드 10개(하4중3상3 표기) → 선택.
   커스텀: 작업별 유형 체크박스(기본3 택1 · 계산 함수 다중 · 분석 택2) → 구성 확인.
3. **시험지 다운로드**(.xlsx) → 사용자가 엑셀에서 풀이.
4. **완성 파일 업로드** → 작업별 채점 결과·총점·오답 해설.
5. (선택) 오답을 오답노트에 누적, 타이머, 재응시.

---

## 8. 단계별 개발 로드맵

- **P1 (지금 착수)**: 데이터 모델 확정 + ExamView 구성기 UI(표준/커스텀 체크박스) + `examBuilder`(시험지 .xlsx 생성) + **계산작업 채점(수식 일치)**. 계산작업 문제 뱅크 우선 저작(차시 1~8 유형).
- **P2**: 기본작업(입력·텍스트나누기·고급필터·서식) + 분석작업 값기반(부분합·통합·목표값·정렬·데이터표) 채점 + 해당 문제 뱅크.
- **P3**: 정의 XML 채점(조건부서식·피벗·시나리오·차트·매크로) + 문제 뱅크. 난이도 태깅 정교화.
- **P4**: 1급 확장, 실시간 문제 생성(LLM) 검토.

---

## 9. 필요 콘텐츠(내가 저작)
기출 유형을 근거로 각 유형×난이도별 문제 JSON을 저작해 `src/data/exam/`에 채운다.
표·데이터·정답은 새로 구성(저작권 안전). 회차가 쌓일수록 표준 10회·커스텀이 풍부해진다.
