# CellLearn 디자인 인벤토리 (현재 상태)

> 목적: 디자인 리뉴얼 논의용 참고 문서. 각 요소에 라벨(H, S, F …)을 붙여 두었으니
> "H-히어로 바꿔줘"처럼 지목해서 대화하면 된다. 아래는 **현재 구현된 그대로**의 정리다.

---

## 0. 공통 디자인 시스템

### 색상 팔레트 (지금 3벌이 따로 존재 — 통합 검토 대상)

**① 앱 전역 (`src/theme.js`, 밝은 톤)**
- 배경 `#edf0ee` (오프화이트) / 카드 `#ffffff` / 옅은패널 `#f5f7f6`
- 기본텍스트 `#132420` / 보조 `#5f6f6a` / 흐림 `#8a9993` / 테두리 `#e4e8e6`
- **딥그린(강조)** `#123a33` / **라임(액센트)** `#c8f26a`
- 의미색: 정답 `#1f9d55` · 오답 `#d64545` · 주의 `#c98a1a`

**② 랜딩 전용 (`LandingPage.jsx`의 `T`)**
- ①과 거의 같지만 별도 정의. 추가로 가격섹션 블랙 `#0b0c0e`, 푸터 `#0d2a25`.

**③ 다이어그램 전용 (`diagrams/shared.jsx`의 `C`, 다크 톤)**
- 슬라이드는 딥그린 카드(`#123a33`) 위에 파랑/보라/앰버 강조. 앱 밝은 톤과 완전히 다른 별세계.

> ⚠️ **디자인 대화 시 첫 결정 포인트:** 이 3벌을 하나로 통합할지, 다이어그램은 다크로 둘지.

### 폰트
- 전체 `'Noto Sans KR', sans-serif` 단일. 굵기 500/700/800 위주.

### 공통 컴포넌트 톤
- **버튼(Pill):** 라운드 999(완전 알약형). 3종 — `lime`(라임 배경), `dark`(딥그린 배경 흰글씨), `outline`(투명+테두리)
- **카드:** 라운드 14~20, 얇은 테두리 1px, 흰 배경. 그림자는 거의 안 씀(결제·로그아웃 버튼만 약한 그림자)
- **아이콘:** 실제 이모지(📖🧮✅📝❌📊) 사용

## 1. 랜딩 페이지 (비회원/첫 진입) — `LandingPage.jsx`

세로로 쌓인 섹션 구조. 위→아래 순서:

- **N. 상단 네비바** — 로고(C+CellLearn) / 가운데 앵커메뉴(홈·학습방식·커리큘럼·수강료) / 우측 "학습 시작"(딥그린 Pill). *모바일은 메뉴 숨김.*
- **H. 히어로** — 라임소프트 뱃지("컴활 실기 전문·2025 신규 오픈") → 대제목("컴활 실기, 최신 학습법으로 한 번에") → 설명문 → 버튼 2개(학습시작/미리보기). *모바일은 "PC에서 이용" 안내 카드.*
- **S. 스탯 카드 줄** — 4칸(딥그린 "N차시" / 흰 "60+ 함수" / 라임 "100% 실습" / 딥그린카드 "설치없이 실습"). 색이 칸마다 다른 게 특징.
- **F. 학습 방식** (딥그린 섹션) — 6개 기능 카드 그리드(개념학습·미니엑셀·파일채점·퀴즈·오답노트·대시보드). 각 카드 상단에 이모지+↗.
- **A. 핵심 강점** (흰 섹션) — 좌: 가짜 대시보드 목업(진도바 3개+통계 2칸) / 우: 강점 3개 목록(◆ 불릿).
- **C. 커리큘럼** (밝은 섹션) — 전 차시 카드 그리드(번호뱃지+제목+"N개 개념·N문제").
- **P. 가격** (블랙 섹션) — 2급/1급 플랜 카드 2개(1급 강조=딥그린) + 하단 "모든 플랜 공통 제공" 밴드.
- **E. 함수/엔진** (흰 섹션) — 좌: 설명+버튼 / 우: 함수 칩 나열(VLOOKUP 등 16개).
- **T. CTA 밴드** (딥그린) — "지금 시작하세요" + 라임 버튼.
- **FT. 푸터** (짙은 그린 `#0d2a25`) — 로고+소개 / 링크 3열(학습·고객지원·문의) / 카피라이트.

## 2. 로그인·회원가입 — `AuthView.jsx` (+ LoginView/SignupView, `authStyles.js`)

- 화면 중앙 단일 카드. "← 홈" 버튼, (키 미설정 시) 경고 배너, 로그인/회원가입 토글.
- *참고: 이 화면만 스타일이 `authStyles.js`(S)에 따로 있어 색 톤이 살짝 다를 수 있음 — 확인 필요.*

## 3. 결제(수강권) — `CheckoutView.jsx`

- 중앙 카드(약한 그림자). 제목 "수강권 결제" → 급수 선택 2칸(2급/1급, 선택 시 딥그린 테두리+틴트) → 상품/금액/기간 요약 → 결제 버튼(딥그린).

## 4. 학습 앱 (로그인 후 메인) — `App.jsx` 셸

좌측 사이드바 + 우측 콘텐츠(상단 sticky 탭) 2단 레이아웃.

- **SB. 사이드바** (`Sidebar.jsx`, 폭 240, 흰 배경) — 로고("컴활 2급 실기") / 📊 대시보드 / ❌ 오답노트(개수뱃지) / "차시 목록"(각 차시 앞 ✓○ 완료표시, 활성=딥그린 배경). 부족분은 "준비 중..." 회색 표시.
- **TB. 상단 탭바** (App.jsx 내부, sticky) — "← 홈" / 차시 진입 시 [📖 개념·📂 실습·📝 퀴즈] 알약탭 / 우측에 (관리자 버튼)·이메일·로그아웃.

### 4-1. 대시보드 — `Dashboard.jsx`
- 상단 통계 4카드(완료차시/퀴즈정답/퀴즈오답/실습오답셀) → "차시별 진도" 패널(차시마다 진도바, 완료=100% 딥그린).

### 4-2. 개념 학습 — `ConceptView.jsx`
- 상단 진행 표시("개념 N/M") → 흰 카드 안에 제목+본문블록(텍스트/불릿/번호/**다이어그램**/다운로드버튼) + 미니엑셀 실습 → 하단 진행 점(dot) → 이전/다음(마지막은 "개념 완료 → 퀴즈 풀기" 라임 버튼).
- **블록 타입:** heading(딥그린 알약 라벨)·text·bullets·numbered·image(React 다이어그램)·download.
- **미니엑셀(`MiniExcel.jsx`):** 실제 엑셀형 셀 그리드+채점(별도 요소, 필요 시 따로 정리 가능).

### 4-3. 엑셀 실습 — `PracticeView.jsx`
- 흰 카드 3단계: ① 파일 다운로드(시트 목록+딥그린 버튼) ② 실습 안내(번호 리스트) ③ 업로드&채점(점선 테두리 버튼) → 채점 결과 카드(정/오답 색 구분) → "복습 퀴즈 풀기" 버튼.

### 4-4. 복습 퀴즈 — `QuizView.jsx`
- 제목+문제수 → (제출 후) 점수 배너(8↑ 초록/미만 빨강) → 문제 카드들(①②③④ 보기 버튼, 선택=딥그린 틴트, 채점 후 정/오답 색) → 오답에 "풀이 보기" 토글 → 제출 버튼 / (제출 후) "✅ 차시 완료" 라임 버튼.

### 4-5. 오답노트 — `WrongNoteView.jsx`
- 제목 → 📂 실습 오답 섹션(시트·셀·입력수식·정답수식) → 📝 퀴즈 오답 섹션(문제·정답·풀이토글). 카드 테두리는 빨강 계열. 없으면 "오답이 없어요!".

## 5. 관리자 — `AdminView.jsx`

- "← 홈" + 제목 → 탭 3개(회원·결제·**진도**) → 표. 진도 탭은 사용자별 완료차시·진도율(막대)·퀴즈평균·최근학습.

## 7. 리뉴얼 시 유의점

- **가장 큰 구조적 이슈:** 색 팔레트가 3벌(`theme.js` / `LandingPage.jsx`의 `T` / `diagrams/shared.jsx`의 `C`)로 흩어져 있음.
  새 디자인을 정하면 **`theme.js` 하나로 통합**하는 걸 권장 — 그래야 한 번 바꿔 전체 반영.
- 스타일은 전부 **인라인 스타일**(Tailwind 클래스 혼용 금지, CLAUDE.md 규칙). 토큰화하려면 theme 객체 확장이 정석.
- 새 방향을 받으면 위 라벨 구조(N/H/S/F/A/C/P/E/T/FT, SB/TB, 4-1~4-5 등)에 그대로 매핑해 적용 가능.
