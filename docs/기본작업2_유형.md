> [A1:H1] 영역은 '선택 영역의 가운데로', 글꼴 크기 '16', 글꼴 스타일 '굵게'로 지정하시오.
> [A1:F1] 영역은 '선택 영역의 가운데로', 글씨체 'HY헤드라인M', 글씨 크기 '16', 행높이 '30'으로 지정하시오.

**슬롯**

- 글꼴: 맑은 고딕(기본) / HY헤드라인M / HY견고딕 / 궁서 / 돋움체 / 굴림체
- 크기: 14 / 16 / 18 / 20
- 스타일: 굵게 / 기울임꼴 / 굵은 기울임꼴
- 밑줄: 이중 실선 / 실선(회계용) / 이중 실선(회계용)

- 밑줄 종류 4가지(실선, 이중 실선, 실선(회계용), 이중 실선(회계용))는 글꼴 대화상자에서만 고를 수 있다.
- 행 높이는 행 머리글 우클릭 → 행 높이.

**슬롯**

- 채우기 색: 황갈색 배경 2, 표준색 계열 (3회)
- 맞춤: 가로·세로 가운데, 텍스트 줄 바꿈

- 채우기 색은 팔레트에서 '테마 색'과 '표준 색'을 구분해서 고른다. 문제에 '표준색 – 노랑'이면 아래쪽 표준 색.

## 유형 3. 사용자 지정 표시 형식 (③, 매회, 가장 자주 틀림)

**문장 형태**
> [A5:A12] 영역은 사용자 지정 표시 형식을 이용하여 숫자 앞에 'GP-'가 항상 표시되고 숫자는 3자리로 표시되게 지정하시오. [표시 예 : 1 → GP-001]
> [F4:F10] 영역은 사용자 지정 표시 형식을 이용하여 숫자 앞에 '*'를 표시하고 숫자 뒤에 '개'를 표시 예와 같이 표시하시오. ▶ [표시 예 : 2 → *2개, 0 → *0개]
> [D5:D12] 영역은 사용자 지정 표시 형식을 이용하여 천단위를 절삭하고 숫자 뒤에 '천원'을 표시하시오. ▶ [표시 예 : 70000 → 70천원, 0 → 0천원]
> [B5:B12] 영역은 사용자 지정 표시 형식을 이용하여 날짜 형식을 바꾸시오. ▶ [표시 예 : 2023-05-15 → 05월 15일(월)]
> [G4:G9] 영역은 표시 예와 같이 표시하시오. [표시 예 : 2690000 → 2.69백만]

**정답 코드 목록 (정답 파일에서 확인)**

| 구분 | 표시 예 | 코드 |
|---|---|---|
| 접두 문자 + 자릿수 | 1 → GP-001 | `"GP-"000` |
| 접두·접미 문자 | 2 → *2개, 0 → *0개 | `"*"0"개"` |
| 접미 문자 | 3 → 3명 | `0"명"` |
| 접미 문자 | 5 → *5일 | `"*"0"일"` |
| 접미 + 천 단위 쉼표 | 12000 → 12,000원 | `#,##0"원"` |
| 백분율 문자 | 15 → 15% (값이 15) | `0"%"` |
| 천 단위 절삭 | 70000 → 70천원 | `#,##0,"천원"` |
| 백만 단위 절삭 | 2690000 → 2.69백만 | `0.00,,"백만"` |
| 날짜 | 2023-05-15 → 05월 15일(월) | `mm"월" dd"일"(aaa)` |
| 날짜 | 2023-05-15 → 5/15(월) | `m/d(aaa)` |
| 날짜 | 2014-03-09 → 3/9(일) | `m/d(aaa)` |
| 날짜 | 2023-05-15 → 23/05(월) | `yy/mm(aaa)` |
| 통화 | 12000 → ₩12,000, 음수 빨강 괄호 | `"₩"#,##0_);[Red]("₩"#,##0)` (통화 범주에서 선택) |
| 기본 제공 | 쉼표 스타일 | 홈 탭 쉼표 버튼 (`_-* #,##0_-;…`) |
| 기본 제공 | 간단한 날짜 | 표시 형식 목록에서 선택 (`mm-dd-yy`) |
| 기본 제공 | 백분율 | `0%` |
| 텍스트 | 숫자를 문자로 | `@` |

**함정**
- 문자는 큰따옴표로 감싼다. `"천원"`, `"개"`. 따옴표 없이 쓰면 오류거나 다른 뜻.
- 0과 #의 차이: 표시 예에 "0 → *0개"가 있으면 `0`을 써야 한다. `#`이면 0이 빈칸.
- 절삭은 코드 끝의 쉼표 개수: `,` 하나가 천, 둘이 백만.
- 요일은 `aaa`(월) / `aaaa`(월요일). 영문은 `ddd`/`dddd`.
- 0"%"(값이 15일 때 15%)와 0%(값이 0.15일 때 15%)는 다르다. 표시 예의 원래 값을 보고 판단.
- "쉼표 스타일"은 사용자 지정이 아니라 홈 탭 버튼. `#,##0`을 직접 쳐도 화면은 같지만 스타일명이 달라진다.

## 유형 5. 이름 정의 (④, 5/11)

**문장**
> [B4:B9], [D4:D9] 영역은 … '제품명'으로 이름을 정의 하시오.

**정답 형태**: 이름 상자에 입력 또는 수식 탭 → 이름 정의. 떨어진 두 범위를 한 이름으로(`'기본작업-2'!$B$4:$B$9,'기본작업-2'!$D$4:$D$9`)도 나온다.

**함정**: 범위를 먼저 선택한 뒤 이름 상자에 치고 Enter. Enter를 안 치면 저장 안 됨. 이름은 공백 불가.

## 유형 6. 메모 (④, 4/11)

**문장**
> [F4] 셀에 '개인 수업 요망'이라는 메모를 삽입한 후 '자동 크기'로 지정하고 항상 표시되도록 하시오.

**슬롯**: 셀 위치, 메모 내용, 자동 크기 여부, 항상 표시 여부

**함정**: 자동 크기는 메모 테두리 우클릭 → 메모 서식 → 맞춤 탭. 메모 안 우클릭이 아니라 테두리에서 해야 한다. 기본으로 들어가는 사용자 이름은 지우고 내용만 남긴다.

## 유형 7. 테두리 (⑤, 매회)

**문장**
> [A4:F12] 영역에 '모든 테두리(⊞)'를 적용하고, [A4:F4] 영역은 '아래쪽 이중 테두리(⊟)'를 적용하여 표시하시오.
> [A3:F10] 영역에 '모든 테두리(⊞)'를 적용한 후 '굵은 바깥쪽 테두리(⊡)'를 적용하여 표시하고 [A3:F3] 영역은 '아래쪽 이중 테두리'를 적용하여 표시하시오.

**슬롯 조합 (정답 파일 기준)**
- 모든 테두리 + 머리글 아래쪽 이중 (5회)
- 모든 테두리 + 굵은 바깥쪽 (5회)
- 모든 테두리 + 굵은 바깥쪽 + 머리글 아래쪽 이중 (2회)
- 대각선 (2급에서 가끔, 이번 11회에는 없음)

**함정**: 순서. 굵은 바깥쪽을 먼저 하고 모든 테두리를 하면 바깥이 얇아진다. 문제에 적힌 순서대로.

## 5문항 구성 규칙 (11회 공통)

1. ①은 반드시 제목. 정렬 + 글꼴 속성 2~3개 + (행 높이).
2. ②는 머리글 행 또는 병합. 셀 스타일이 가장 많다.
3. ③④ 중 하나는 반드시 사용자 지정 표시 형식이고, 표시 예가 붙는다. 날짜와 숫자가 한 항목에 같이 나오기도 한다.
4. ③④의 나머지 하나는 맞춤·이름·메모·쉼표 스타일 중 1~2개를 묶는다.
5. ⑤는 반드시 테두리. 모든 테두리가 기본이고 이중/굵은 바깥쪽이 추가된다.

이 규칙으로 문항을 생성하면 실제 시험과 같은 모양이 된다. 데이터 표는 6~10행, 5~8열이고 제목·빈 행·머리글·데이터 순서(1행 제목, 2행 빈 행, 3행 머리글, 4행부터 데이터)가 고정이다.
